## 📌 О проекте

Aura IT — студия, которая занимается разработкой, инфраструктурой и автоматизацией
для промышленных предприятий. Этот репозиторий — её сайт-визитка: одна страница,
без фреймворков и сборщиков, с собственным рантаймом для анимаций.

| Параметр | Значение |
| --- | --- |
| 🌐 Продакшн | [aurait.onrender.com](https://aurait.onrender.com/) |
| 🧱 Стек | HTML, CSS, ванильный JavaScript |
| 📦 Зависимости | нет — только статические файлы |
| 🎯 Формат | одностраничный сайт (single page) |

---

## 🗂 Структура проекта

```text
aura-it/
├── index.html              # вся разметка страницы
├── diag.html               # отладочная страница (см. ниже)
│
├── assets/css/
│   ├── main.css            # точка входа: порядок @import задаёт весь каскад
│   ├── base/               # токены, сброс, раскладка, адаптив, профили, движение
│   ├── components/         # шапка, кнопки, бургер, терминал, переключатель, превью
│   └── sections/           # hero, компетенции, услуги, процесс, проекты, контакты
│
├── assets/js/
│   ├── core/aura.js        # общий рантайм и реестр модулей
│   ├── main.js             # порядок загрузки модулей
│   └── modules/            # по одному файлу на возможность
│
└── assets/img/             # фавиконка и картинка для соцсетей
```

## 🧩 Архитектура

<details>
<summary><b>CSS — каскад через одну точку входа</b></summary>

<br />

`assets/css/main.css` — единственный вход. Порядок `@import` в нём задаёт весь
каскад, поэтому специфичность и `!important` практически не нужны.

| Слой | Что внутри |
| --- | --- |
| `base/` | токены, сброс, раскладка, адаптив, профили производительности, движение |
| `components/` | шапка, кнопки, бургер, терминал, переключатель темы, превью |
| `sections/` | hero, компетенции, услуги, процесс, проекты, контакты |

Правило: новый файл добавляется в нужный слой **и** прописывается в `main.css`
в правильном месте — иначе он не подключится.

</details>

<details>
<summary><b>JS — рантайм и модули</b></summary>

<br />

- **`core/aura.js`** — общий рантайм: реестр модулей, единые слушатели `scroll`
  и `resize`, сглаженная скорость скролла, флаги производительности устройства.
- **`main.js`** — задаёт порядок загрузки и инициализации модулей.
- **`modules/*.js`** — одна возможность = один файл. Модуль регистрируется в
  рантайме и получает готовый контекст, ничего не слушая сам.

Так на странице живёт один `requestAnimationFrame`-цикл и по одному слушателю
на событие, а не по штуке на каждый эффект.

</details>

<details>
<summary><b>Производительность</b></summary>

<br />

- Единый rAF-цикл и общие слушатели вместо дублирующихся подписок.
- Профили устройства: тяжёлые эффекты отключаются на слабых машинах и мобильных.
- Уважается `prefers-reduced-motion` — анимации упрощаются или выключаются.
- Никаких аллокаций в горячем кадре: буферы и объекты переиспользуются.

</details>

## 🚀 Запуск локально

```bash
git clone https://github.com/badVIno-ctrl/auraIT.git
cd auraIT/aura-it
```

Сборка не нужна — это статические файлы. Достаточно любого локального сервера:

```bash
# Python
python3 -m http.server 5173

# или Node
npx serve .
```

Затем открой <http://localhost:5173>.

> [!NOTE]
> Открывать `index.html` двойным кликом (через `file://`) не стоит: часть
> модулей и путей рассчитана на нормальный HTTP-origin.

## 🛠 Отладка

`diag.html` — служебная страница для диагностики: показывает состояние рантайма,
активные модули, определённый профиль производительности и метрики кадра.
Удобно, когда нужно понять, почему эффект не запустился или просел FPS.
